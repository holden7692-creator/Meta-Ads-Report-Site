Caveats and Assumptions

  • 本报告把 Campaign name + Ad set name + Ad name 作为一条广告，避免同名广告跨 ad set 被合并。Purchases 空值按 0 单处理，inactive 但出现在日报中的广告也纳入分母，因为这些广告代表曾经投放或仍有归因表现。
  • 新增广告日销增量采用“出单数 / 广告投放日行数”，因此它是一个包含无出单广告后的实际平均效率。昨日上新广告按 Ad name 中包含 2026-11-23 的日期标记识别。
  • 报表只统计能从名称明确匹配到已识别产品的广告；仍有 0 行未分配到产品，它们合计 0 单、$0.00 花费。如果这些订单实际属于某个产品，需要在订单或素材层面补充分配规则后复算。
  • 180 Awning 和 180XL 共用11月 177.45 单/月目标，即 5.92 单/日；目标缺口和新增广告需求在“180 Awning + 180XL”目标组中合并计算，广告状态盘点、昨日上新和每条广告明细仍按原产品拆开。

  • 历史趋势和环比读取 meta-api-history.xlsx；当前可用历史范围为 2026-10-25 至 2026-11-23。所有 CPA、ROAS、CVR、CTR、CPC、CPM 与 Frequency 均由所选周期汇总分子和分母重新计算，不直接平均日比率。
