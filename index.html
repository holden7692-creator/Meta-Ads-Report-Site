  • 新增广告日销增量采用“出单数 / 广告投放日行数”，因此它是一个包含无出单广告后的实际平均效率。昨日上新广告按 Ad name 中包含 2026-09-25 的日期标记识别。
  • 报表只统计能从名称明确匹配到已识别产品的广告；仍有 0 行未分配到产品，它们合计 0 单、$0.00 花费。如果这些订单实际属于某个产品，需要在订单或素材层面补充分配规则后复算。
  • 180 Awning 和 180XL 共用9月 109.96 单/月目标，即 3.67 单/日；目标缺口和新增广告需求在“180 Awning + 180XL”目标组中合并计算，广告状态盘点、昨日上新和每条广告明细仍按原产品拆开。
  • 9月销售额目标合计为 $452,766.51；周目标使用已确认的固定目标，合计 153.84 单和 $102,237.60，周区间按周一至周日。目标进度中的实际销售额使用 Meta 的 Purchases conversion value，销量使用 Purchases。
  • 历史趋势和环比读取 meta-api-history.xlsx；当前可用历史范围为 2026-08-27 至 2026-09-25。所有 CPA、ROAS、CVR、CTR、CPC、CPM 与 Frequency 均由所选周期汇总分子和分母重新计算，不直接平均日比率。
  • 优质广告健康监控的门槛为过去 7 天 Purchase ≥ 4 单；“可能疲软”是预警规则，主要参考近 3 日与前 3 日的 CVR、ROAS、CPA、点击率变化，以及 Active 广告最近 3 个报表日是否连续无出单，不替代人工结合预算、受众和素材判断。
  • Purchases 是 Meta 归因口径，不等同于后台最终订单归因；如果有 Shopify/ERP 产品级订单数据，应作为下一步校验。
  • 过去 7 天样本较短，新广告预计增量是近期经验均值，不代表稳定长期效率。
