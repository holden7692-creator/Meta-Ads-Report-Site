  • 本报告把 Campaign name + Ad set name + Ad name 作为一条广告，避免同名广告跨 ad set 被合并。Purchases 空值按 0 单处理，inactive 但出现在日报中的广告也纳入分母，因为这些广告代表曾经投放或仍有归因表现。
