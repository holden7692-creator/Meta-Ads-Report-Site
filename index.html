  • 本报告把 Campaign name + Ad set name + Ad name 作为一条广告，避免同名广告跨 ad set 被合并。Purchases 空值按 0 单处理，inactive 但出现在日报中的广告也纳入分母，因为这些广告代表曾经投放或仍有归因表现。

  • 报表只统计能从名称明确匹配到已识别产品的广告；仍有 0 行未分配到产品，它们合计 0 单、$0.00 花费。如果这些订单实际属于某个产品，需要在订单或素材层面补充分配规则后复算。
  • 180 Awning 和 180XL 共用10月 161.52 单/月目标，即 5.21 单/日；目标缺口和新增广告需求在“180 Awning + 180XL”目标组中合并计算，广告状态盘点、昨日上新和每条广告明细仍按原产品拆开。
  • 10月目标总计采用目标表中的总计值：923.69 单和 $608,837.52；产品行采用截图中各产品的可见目标。周目标使用已确认的固定目标，合计 208.58 单和 $137,479.44，周区间按周一至周日。目标进度中的实际销售额使用 Meta 的 Purchases conversion value，销量使用 Purchases。
  • 历史趋势和环比读取 meta-api-history.xlsx；当前可用历史范围为 2026-09-10 至 2026-10-09。所有 CPA、ROAS、CVR、CTR、CPC、CPM 与 Frequency 均由所选周期汇总分子和分母重新计算，不直接平均日比率。
  • 优质广告健康监控的门槛为过去 7 天 Purchase ≥ 4 单；“可能疲软”是预警规则，主要参考近 3 日与前 3 日的 CVR、ROAS、CPA、点击率变化，以及 Active 广告最近 3 个报表日是否连续无出单，不替代人工结合预算、受众和素材判断。
